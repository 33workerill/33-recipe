# 33 RECIPE

**Personal Recipe Studio** — персональное веб-приложение для создания, оформления и локального хранения рецептов. Рабочее пространство включает редактор, библиотеку, локальные фотографии и студию предпросмотра с шестью стилями, несколькими форматами и сохраняемыми настройками. Экспорт оформленного рецепта и точная печатная пагинация запланированы на будущий этап.

## Стек и требования

React 19, TypeScript, Vite, Tailwind CSS 4, компоненты shadcn/ui и Lucide React. Нужны Node.js 24 LTS и npm 11. Версия Node указана в `.nvmrc`.

## Локальный запуск

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`).

- `/` — рабочее пространство: редактор, локальная библиотека, недавние рецепты и настройки резервного копирования. Данные остаются только в текущем браузере; очистка данных сайта может их удалить.
- `/ui` — интерактивный обзор дизайн-системы. Прямой переход и перезагрузка работают на Vercel через `vercel.json`.
- Переключатель темы поддерживает светлый, тёмный и системный режимы; выбор сохраняется в браузере.
- На телефоне навигация открывается через меню, а редактор и предпросмотр переключаются отдельными кнопками. Рецепты и фото остаются в IndexedDB текущего браузера.

## Команды

| Команда                | Назначение                                   |
| ---------------------- | -------------------------------------------- |
| `npm run dev`          | Сервер разработки                            |
| `npm run build`        | Проверка типов и production-сборка в `dist/` |
| `npm run preview`      | Локальный просмотр сборки                    |
| `npm run lint`         | ESLint                                       |
| `npm run typecheck`    | TypeScript strict check                      |
| `npm run format`       | Форматирование Prettier                      |
| `npm run format:check` | Проверка форматирования                      |
| `npm run test`         | Vitest в режиме наблюдения                   |
| `npm run test:run`     | Однократный прогон Vitest                    |

Перед отправкой изменений запустите `npm ci`, `npm run lint`, `npm run typecheck`, `npm run format:check`, `npm run test:run` и `npm run build`. JSON backup включает рецепт и метаданные, но не файлы изображений.

## Развёртывание

GitHub Actions проверяет изменения, Vercel собирает production из `main` и preview из рабочих веток. Используются Vite, `npm run build`, `dist` и `npm ci`. Подробности подключения указаны в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Слияние PR в `main` выполняется только после одобрения владельца.
