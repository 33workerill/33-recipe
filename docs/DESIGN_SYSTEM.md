# 33 RECIPE — дизайн-система

## Направление

Современный монохромный интерфейс личной студии рецептов: ясная иерархия текста, спокойные поверхности, тонкие разделители и минимальное движение. Светлая и тёмная темы используют одни и те же семантические роли. Цвет исключения применяется только к разрушительному действию и ошибке.

## Палитра и токены

Источник значений — [`src/styles/index.css`](../src/styles/index.css). Компоненты обращаются к переменным через классы Tailwind CSS v4 (`bg-background`, `text-foreground`, `border-border`, `focus-visible:ring-ring`). Значения задаются в OKLCH, чтобы роли можно было менять централизованно.

| Роль             | CSS-переменная        | Светлая | Тёмная | Использование             |
| ---------------- | --------------------- | ------- | ------ | ------------------------- |
| Background       | `--background`        | 0.985   | 0.16   | фон страницы              |
| Foreground       | `--foreground`        | 0.20    | 0.94   | основной текст            |
| Surface / Card   | `--surface`, `--card` | 1.00    | 0.21   | карточки и панели         |
| Muted            | `--muted`             | 0.955   | 0.26   | вторичный фон             |
| Muted Foreground | `--muted-foreground`  | 0.43    | 0.75   | подписи                   |
| Border           | `--border`            | 0.89    | 0.35   | разделители               |
| Input            | `--input`             | 0.86    | 0.39   | границы полей             |
| Ring / Focus     | `--ring`              | 0.40    | 0.78   | видимый фокус             |
| Primary          | `--primary`           | 0.22    | 0.91   | главное действие          |
| Secondary        | `--secondary`         | 0.935   | 0.29   | вторичное действие        |

Числа в таблице — светлота OKLCH; полные значения и соответствующие foreground-токены находятся в CSS. `--popover`, `--accent` и `--sidebar-*` сохраняют совместимость с shadcn/ui. Успех и предупреждение остаются нейтральными по цвету и различаются текстом и иконкой.

## Типографика

Системный стек включает доступные на платформе шрифты с кириллицей: `ui-sans-serif`, `system-ui`, `Segoe UI` и альтернативы. Сторонние шрифтовые файлы не загружаются.

| Стиль       | CSS-класс       | Размер и роль                  |
| ----------- | --------------- | ------------------------------ |
| Display     | `.type-display` | 48–104 px, акцентный заголовок |
| Heading 1   | `.type-h1`      | 38–64 px, заголовок страницы   |
| Heading 2   | `.type-h2`      | 28–40 px, раздел               |
| Heading 3   | `.type-h3`      | 20 px, карточка                |
| Body Large  | `.type-body-lg` | 18 px, вводный текст           |
| Body        | `.type-body`    | 16 px, основной текст          |
| Small       | `.type-small`   | 14 px, пояснение               |
| Caption     | `.type-caption` | 12 px, подпись                 |
| Label       | `.type-label`   | 14 px, подпись поля            |
| Button Text | `.type-button`  | 14 px, действие                |

Крупные заголовки адаптируются через `clamp()`; длинные слова переносятся. Для основного текста используется увеличенный межстрочный интервал, для заголовков — отрицательный трекинг.

## Отступы, скругления и движение

Шкала отступов `--space-1/2/3/4/6/8/12` соответствует **4 / 8 / 12 / 16 / 24 / 32 / 48 px**. Tailwind использует ту же базовую 4 px сетку. Радиусы: Small 6 px, Medium 10 px, Large 14 px, Extra Large 20 px.

Переходы короткие: `--motion-fast: 120ms`, `--motion-base: 180ms`, кривая `--motion-ease`. При `prefers-reduced-motion: reduce` CSS сокращает анимации и выключает плавную прокрутку. Бесконечных декоративных анимаций нет; вращение индикатора загрузки работает только во время демонстрации состояния.

## Темы

`ThemeProvider` предлагает **Light**, **Dark** и **System**. Выбор хранится в `localStorage`; System реагирует на событие `matchMedia('(prefers-color-scheme: dark)')`. Скрипт в `index.html` применяет выбранный класс до загрузки React, чтобы уменьшить мигание неверной темы. Переключатель использует доступные названия и `aria-pressed`.

Токены этой системы относятся к **App Theme**. Будущие Recipe Themes должны быть ограничены областью самого рецепта и не наследовать режим интерфейса при печати.

## Компоненты и состояния

Примитивы shadcn/ui находятся в `src/components/ui/`:

- Controls: Button (Primary, Secondary, Outline, Ghost, Destructive), Input, Textarea, Label, Checkbox, Switch, Radio Group, Select.
- Navigation: Tabs, Dropdown Menu, Tooltip, Accordion, Separator.
- Containers: Card, Dialog, Sheet.
- Feedback: Badge, Alert, Skeleton.

Интерактивные компоненты имеют состояния default, hover, active, focus-visible и disabled. Поля поддерживают `aria-invalid`; кнопки показывают loading через `aria-busy` и индикатор. Иконки Lucide внутри кнопок без текста требуют `aria-label`. Диалог и панель используют управление фокусом Radix. Сообщения о статусе передаются также текстом.

## Использование и ограничения

Страница `/ui` показывает токены, все группы компонентов и их основные состояния. Это служебный Showcase с небольшим количеством демонстрационных данных. Для нового интерфейса сначала выбирайте существующий семантический токен и компонент; не добавляйте произвольные цвета в JSX. Демонстрационный экран не является редактором рецептов. Toast не подключён: на Phase 02 достаточно встроенных Alert и статуса, а дополнительная зависимость пока не нужна.
