# Редактор и локальная библиотека — Phase 05 Fast Track

Редактор использует типы и проверки Phase 04 напрямую. Пустой черновик создаётся только по действию пользователя и сразу записывается в IndexedDB. Название, описание, категория, теги, группы ингредиентов, шаги, порции, время, сложность, заметки, советы и пищевая ценность редактируются независимо от будущих макетов и экспорта. Статус «Готов к оформлению» означает успешную проверку полноты; неполные черновики тоже сохраняются.

## Сохранение

`RecipeRepository` хранит по одному сериализованному рецепту и номеру ревизии на ID. Каждая запись проверяется Recipe Model. Запись читает текущую ревизию и обновляет её в одной IndexedDB-транзакции. Если другая вкладка уже изменила запись, старая версия отклоняется; перезаписи без предупреждения нет. При неизменном содержимом `updatedAt` и ревизия не меняются. При изменении `updatedAt` становится строго новее прежнего времени.

Редактор держит последние изменения в памяти и сохраняет их после паузы ввода либо по кнопке. Сохранения идут последовательно, а при новом вводе во время записи отправляется последняя версия. Переход к другой записи или разделу ждёт завершения записи; ошибка оставляет введённые данные в редакторе и показывает кнопку повтора. Некорректное промежуточное числовое значение остаётся в поле, но не попадает в модель и блокирует сохранение до исправления. При закрытии страницы с несохранёнными данными браузер показывает предупреждение. Запись, не завершённая до закрытия браузера, не гарантирована.

## Библиотека и резервная копия

Библиотека сортируется по времени изменения и ищет по названию. Список недавних хранит только ID в `localStorage`, удалённые ID отфильтровываются. Дублирование выдаёт новые UUID рецепту и всем вложенным сущностям, включая медиа-ссылки. Удаление подтверждается.

В настройках можно скачать один JSON-файл библиотеки и импортировать его после подтверждения. Каждый рецепт и версия схемы проверяются до записи. Импорт выполняется одной транзакцией: при повторяющемся или уже существующем ID весь импорт отменяется. JSON backup включает рецепты и метаданные изображений, но не бинарные файлы; это явно указано в интерфейсе. Изображения хранятся Blob-записями в отдельном IndexedDB store версии 2.
