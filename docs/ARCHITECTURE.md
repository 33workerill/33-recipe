# Архитектура

## Реализовано

```text
src/
  App.tsx                         состояние навигации, sidebar и переключения панелей
  Root.tsx                        выбор между / и /ui без маршрутизатора
  components/shell/
    AppSidebar.tsx                desktop sidebar, мобильный Sheet и выбор темы
    EditorWorkspace.tsx           визуальная структура будущего редактора
    PreviewPanel.tsx              нейтральная пустая область предпросмотра
    WorkspacePage.tsx             пустые Library / Recent и настройки темы
    navigation.ts                 разделы оболочки
  components/ui/                  примитивы shadcn/ui (Radix)
  pages/UiShowcase.tsx            демонстрация Design System
  theme/                          light / dark / system, хранение, системные изменения
  styles/index.css                семантические токены, типографика и motion
  test/setup.ts                   окружение Vitest / Testing Library
index.html                        раннее применение темы до загрузки React
vercel.json                       rewrite прямого запроса /ui на index.html
```

`Root` выбирает страницу по `window.location.pathname`. Главный маршрут `/` сразу показывает рабочее пространство; `/ui` загружается отдельным чанком. Для этих двух маршрутов библиотека маршрутизации не нужна.

На широких экранах отображаются sidebar, центральная область и предпросмотр. До ширины `xl` редактор и предпросмотр переключаются локальным UI-состоянием. На мобильных устройствах sidebar открывается через Sheet. Навигация между редактором, коллекцией, недавними и настройками также хранится только в памяти React. Пустые состояния не содержат фиктивных рецептов.

Секции каркаса редактора используют Accordion из Design System. Недоступные поля, сохранение, создание и экспорт явно обозначены. Они не записывают данные. Бумажная поверхность в пустом предпросмотре имеет отдельные нейтральные CSS-переменные и сохраняет один вид при смене темы приложения; это ещё не макет печатного рецепта.

Тема интерфейса задаётся классом `.dark` на `html` и семантическими CSS-переменными. Выбор `light | dark | system` хранится под ключом `33-recipe-app-theme`; скрипт в `index.html` применяет класс до загрузки React.

## Границы проекта

Статический клиент пока не имеет API, базы данных, авторизации и фоновых заданий. Phase 03 не вводит Recipe Model, редактирование, хранение, Recipe Renderer или Export. Будущие **Recipe Data**, **Layout**, **Recipe Theme** и **Export** получат отдельные границы. App Theme управляет только интерфейсом и не определяет оформление будущих печатных рецептов.
