# Архитектура

## Реализовано в Phase 01

```text
src/
  App.tsx          временный стартовый экран
  App.test.tsx     тест содержимого экрана
  main.tsx         точка входа React
  styles/index.css Tailwind и базовые глобальные стили
  test/setup.ts    окружение Vitest / Testing Library
vite.config.ts     React, Tailwind, алиас @/, Vitest
components.json    конфигурация shadcn/ui
```

Статический клиент React/Vite не имеет API, базы данных, авторизации и фоновых заданий. UI пока не содержит бизнес-логики.

## Будущие границы

- **Recipe Data:** структура и валидация содержимого рецепта.
- **Layout:** правила компоновки рецепта и печатных форматов.
- **Theme:** визуальные параметры, не меняющие содержимое.
- **Export:** преобразование выбранных данных и компоновки в файл.

Эти границы служат ориентиром для следующих решений. Классы, модели и сервисы для них на Phase 01 не создаются.
