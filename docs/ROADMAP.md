# Дорожная карта

Master Plan 1.0 упоминает 15 этапов. В переданном задании подробно определён только **Phase 01: Foundation**; названия, порядок и критерии Phase 02–15 не приложены. Мы не подменяем утверждённый план предположениями.

| Этап            | Состояние                                                                  |
| --------------- | -------------------------------------------------------------------------- |
| 01 — Foundation | В работе: инфраструктура, временный экран, CI, документация, GitHub/Vercel |
| 02–15           | Ожидают точного текста Master Plan 1.0 и отдельного задания                |

Будущие возможности из концепции: редактор, предпросмотр, шаблоны, библиотека, экспорт, AI Prompt Studio и кулинарная книга. Их привязка к конкретным этапам пока не подтверждена.
