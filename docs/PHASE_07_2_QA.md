# Phase 07.2 — проверка пагинации

Дата: 2026-10-27. Использован реальный Chromium в in-app browser с локальным Vite dev server.

## Матрица

- Desktop: 1440 × 1000, 168 сочетаний, 2617 страниц, 0 ошибок.
- Mobile: 375 × 812, 168 сочетаний, 2617 страниц, 0 ошибок.
- Число страниц совпало между viewport во всех 168 сочетаниях.
- 6 стилей × 10 форматов, обе ориентации A4/A5 и Duplex, обычный и длинный рецепт. Длинный вариант использует 120% типографику.
- «Пицца Маргарита — ТЕСТ» дополнена только в памяти теста обложкой и фото шага. Длинный вариант содержит увеличенные описание, инструкции, заметки к шагам, советы и общие заметки.
- Для каждой страницы проверены физические ширина и высота листа, прямоугольники всех вложенных элементов и текстовых строк относительно печатной области, точное восстановление текста каждого исходного блока и количество изображений.
- Дополнительно при обеих ширинах прошли A4 без фото и A5 с неразрывным словом из 2400 символов.

## Проверка интерфейса

- Monochrome A4 с обложкой и фото шага: 2 страницы; первая и продолжение просмотрены визуально. Основной текст 10 pt, границы и поля сохранены.
- В приложении A4 Duplex: обе стороны рядом при 1440 px, следующая пара доступна клавишей Enter.
- При 375 px показывается одна выбранная сторона, переключение на оборот доступно клавишей Enter; ширина документа не превышает viewport.
- Смена экранного масштаба не влияет на состав страниц. Long Note — единственный формат с адаптивной высотой.

## Повторение

Откройте `/tests/layout-browser.html` на dev server и нажмите «Проверить все страницы». Селектор набора позволяет отдельно воспроизвести Long Note, отсутствие фотографии и неразрывный текст. Страница теста и её фикстуры не входят в production entry и не обращаются к IndexedDB, сохранению или библиотеке.

Unit-регрессии в `presentation/layout.test.ts` проверяют суммарную композицию фото/заголовка, ингредиентов, шагов, КБЖУ и советов, порядок Duplex и точное сохранение фрагментированного текста. Реальную геометрию проверяет браузер, а не jsdom.

## Проверки проекта

ESLint, TypeScript strict, Prettier, 12 файлов / 51 тест Vitest и production build прошли. В локальном runtime отсутствует команда npm, поэтому проверки запускались установленными исполняемыми файлами проекта; локальный `npm ci` недоступен. Чистую установку проверяет GitHub Actions. Vite сохранил предупреждение о начальном JS-бандле более 500 kB: 550.24 kB minified / 170.23 kB gzip.
